# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities privately through GitHub:
**https://github.com/belohnung/justserve/security/advisories/new**. Do not open a public
issue. Please include:
- the affected version: the `version` in the `config` log record, or the image digest;
- the configuration;
- steps to reproduce;
- the impact you expect.

We acknowledge reports, keep you informed while we fix them, and agree a disclosure
date with you. Fixes ship as a new patch release. Each one comes with an advisory at
https://github.com/belohnung/justserve/security/advisories naming the affected and fixed
versions.

## Supported versions

The latest release receives security fixes. Releases are never patched in place.
